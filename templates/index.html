How to use this page

  • Monitor controls: press Start to run the price checker continuously in the background. It repeats every N minutes (adjustable in the bar above, default 30) and keeps running even if you close this page; output goes to config/monitor.log. The MQTT host box sets where readings are published (defaults to the container's MQTT_HOST variable; empty turns publishing off). Check now runs a single pass immediately without disturbing the schedule. Press Stop to end it.
  • Add a product: paste any Amazon URL into the "URL" box at the bottom (long links are fine — they're shortened automatically), set your target price as the "Threshold", give the MQTT topic a name (e.g. garden_kneeler) — the apm/ prefix is added for you if you leave it off — and press the + button. The title and current price are fetched from the page right away.
  • Edit: change the URL, Threshold or MQTT Topic directly in the table, then press the floppy-disk Save icon to keep your changes.
  • Reorder: on a computer, drag a row by its grip handle (≡) to move it; on a phone or tablet, use the up/down arrow buttons at the bottom of each row. The new order is saved to the CSV.
  • Remove: press the trash-can Delete icon on a row to stop monitoring it (you'll be asked to confirm first).
  • Target Met shows Yes once the current price drops below the Threshold — this is what Home Assistant sees.
  • MQTT Topic is the topic this row's readings are published to in Home Assistant. It's pre-filled when you add a row — change it if you want a different topic (no spaces, # or + allowed).
  • The Title, Current Price, Target Met, Time Stamp and In Stock columns are updated automatically by the background monitor script, so they're read-only here.
